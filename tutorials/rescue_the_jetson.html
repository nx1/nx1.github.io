Fixes to try first: Virtual Terminal ---------------- On the blank boot screen try and press: Ctrl + Alt + F3 or try F2 F4 & F5 This is a shortcut to access the linux terminal that doesn't require a gui running or screen, it might work. USB-Cable Debugging ------------------- See https://wiki.seeedstudio.com/jetson_debug_guide/ for more information It is possible to plug in a USB cable to the jetson and turn-on the debug switch and access the terminal bypassing the operating system completely. 1. Connect the host computer to the jetson via the Debug USB-C Port. 2. On the host computer run: ls /dev/ttyACM* /dev/ttyUSB* The Jetson is usually displayed as /dev/ttyACM0 or /dev/ttyUSB0. 3. Connect to the jetson using: sudo screen /dev/ttyACM0 115200 This should drop you into the linux command line Re-Flashing ----------- FLASHING USING CLI Hardware Requirements: Jetson PC (Orin NX) unit that needs to be set up Jetson PC power supply A USB type-A to USB-C cable (for Jeston PC to host) Display with HDMI cable (for Jetson PC) USB dongle and mouse and keyboard (for Jetson PC) Wifi Adaptor (there is no wifi adaptor present in nx module) -> make sure its intel wifi chip only.
