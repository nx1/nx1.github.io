1. Virtual Terminal [^]

On the blank boot screen, try pressing: 
Ctrl + Alt + F3   # or try F2, F4, or F5
This is a shortcut to access a Linux TTY terminal without requiring a GUI or display manager to be running. If the kernel booted cleanly, it should drop you straight into a login prompt.

2. USB-Cable Debugging [^]

See the Seeed Studio Jetson Debug Guide for full details. It is possible to plug a USB cable into the Jetson, enable the debug switch, and access the serial console directly, bypassing the OS display stack. 1. Connect the host computer to the Jetson via the Debug USB-C port. 2. On the host computer, check which serial device appeared: 
> ls /dev/ttyACM* /dev/ttyUSB*
The Jetson usually appears as /dev/ttyACM0 or /dev/ttyUSB0. 3. Connect to the Jetson over serial: 
> sudo screen /dev/ttyACM0 115200
This should drop you into the Linux command line.

3. Re-Flashing: Hardware Requirements [^]

If neither TTY nor serial debugging recovers the machine, re-flash via CLI using an Ubuntu 22.04 host PC. Required hardware: - Jetson PC (Orin NX) unit that needs to be set up - Jetson PC power supply - USB Type-A to USB-C cable (for Jetson PC to host) - Display with HDMI cable (for Jetson PC) - USB dongle with mouse and keyboard (for Jetson PC) - Wi-Fi adapter (no Wi-Fi chip is built into the NX module; use Intel Wi-Fi only) - Extendable antennas for the Wi-Fi adapter

4. Port Connections & Image Download [^]

Use the host Ubuntu 22.04 PC to flash the Jetson Linux image (firmware update, Ubuntu 22.04, JetPack 6.0+). Connections to make: 
Display      -> Port 6 (to Monitor via HDMI)
USB dongle   -> Port 7 (for keyboard and mouse)
Power cable  -> Port 5 (to power adapter)
USB-C        -> Port 9 (to host computer USB Type-A)
Start up the Ubuntu 22.04 host PC and download the flashing image from the Seeed Studio documentation link on that machine. Note that the archive is roughly 16 GB, so downloading it will take some time.

5. Enter Force Recovery Mode [^]

1. Switch the toggle on the reComputer Super to RESET / REC mode: 
reComputer Super panel:
ACT | SIM | PWR | USB 3.2 x3 | Power In | Display | USB 3.2 | ETH 1 | ETH 0
DC 12-19V | OFF ON REC | Debug / Device Connect | USB Type-C for Flash
2. Power on the reComputer Super by connecting the power cable. 3. Connect the Jetson to the host computer (USB Type-A on the Ubuntu host, USB Type-C on the Jetson flash port). 4. On the Ubuntu host PC, open a terminal and run lsusb: 
(base) seeed@seeed-MS-7C94:~$ lsusb
Bus 006 Device 001: ID 1d6b:0003 Linux Foundation 3.0 root hub
Bus 005 Device 001: ID 1d6b:0002 Linux Foundation 2.0 root hub
Bus 004 Device 001: ID 1d6b:0003 Linux Foundation 3.0 root hub
Bus 003 Device 001: ID 1d6b:0002 Linux Foundation 2.0 root hub
Bus 002 Device 001: ID 1d6b:0003 Linux Foundation 3.0 root hub
Bus 001 Device 003: ID 1462:7c94 Micro Star International MYSTIC LIGHT
Bus 001 Device 002: ID 05e3:0608 Genesys Logic. Inc. Hub
Bus 001 Device 018: ID 0955:7523 NVIDIA Corp. APX   <-- confirms recovery mode
Bus 001 Device 001: ID 1d6b:0002 Linux Foundation 2.0 root hub
If you see NVIDIA Corp. APX (0955:7523), the Jetson is in force recovery mode.

6. Extract & Flash via CLI [^]

Once the 16 GB image has finished downloading (typically in ~/Downloads/), extract it and run the flash script from inside the extracted folder: 
> cd ~/Downloads/
> sudo tar xpf <image_name>
# For example:
> sudo tar xpf mfi_recomputer-super-orin-nx-16g-j401-6.2-36.4.3-2025-05-22.tar.gz
> cd <image_name>

> sudo ./tools/kernel_flash/l4t_initrd_flash.sh --flash-only --massflash 1 --network usb0 --showlogs
Flashing takes up to 10 minutes. Look for output like this at the end: 
[ 307]: l4t_flash_from_kernel: Successfully flash the qspi
[ 307]: l4t_flash_from_kernel: Flashing success
[ 307]: l4t_flash_from_kernel: The device size indicated in the partition layout xml is smaller than the actual size. This utility will try to fix the GPT.
Flash is successful
Reboot device
Cleaning up ...

7. Post-Flash Reboot & Verification [^]

1. Turn the REC / RESET toggle back off. 2. Disconnect the Jetson power plug and reconnect it to cold-boot. 3. Connect the monitor via HDMI and complete the initial on-screen Jetson setup. 4. Open a terminal on the Jetson and verify networking and JetPack:
